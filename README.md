# Git: Коротко про Головне

Git — це сучасна **розподілена система керування версіями (VCS)**. Вона створена для ефективного відстеження змін у файлах проєкту (найчастіше — у вихідному коді) та координації роботи між багатьма розробниками.

## Ключові Переваги та Властивості Git:

* **Відстеження Історії:** Зберігає повну історію всіх змін, дозволяючи легко переглядати попередні стани проєкту та повертатися до них.
* **Галуження та Злиття (Branching & Merging):** Дозволяє створювати незалежні лінії розробки (гілки) для нових функцій чи виправлень, а потім легко об'єднувати їх з основною гілкою. Це одна з найпотужніших можливостей Git.
* **Розподіленість:** Кожен розробник має повну копію репозиторію на своєму комп'ютері, включаючи всю історію. Це забезпечує надійність та дозволяє працювати автономно (офлайн).
* **Швидкість:** Більшість операцій (коміт, створення гілки, злиття) виконуються локально і дуже швидко.
* **Цілісність Даних:** Git використовує криптографічне хешування (SHA-1) для забезпечення цілісності всіх даних та історії проєкту. Неможливо змінити історію безслідно.
* **Область Підготовки (Staging Area):** Надає гнучкість у формуванні комітів, дозволяючи точно вибрати, які зміни включити до наступного збереження стану.

Git є стандартом де-факто для керування версіями у сучасній розробці програмного забезпечення, допомагаючи командам працювати ефективніше та підтримувати код у належному стані.
